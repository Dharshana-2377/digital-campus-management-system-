# Digital Campus Management System

## 📌 Project Description
The Digital Campus Management System is a web-based application designed to manage basic campus activities digitally. It provides a simple platform to display student details, course information, and campus announcements.

This project aims to reduce manual work and make campus information management easier and more organized.

## 🎯 Objectives
- To manage student information.
- To display course details.
- To maintain campus announcements.
- To provide easy access to campus information.
- To reduce paperwork through digital management.

## ✨ Features
- Add student details.
- View student records.
- Display available courses.
- Add campus announcements.
- Simple and user-friendly interface.

## 🛠️ Technologies Used
- HTML – Structure of the application.
- CSS – Styling and design.
- JavaScript – Application functionality.

## 🚀 How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter student details.
5. View and manage campus information.
